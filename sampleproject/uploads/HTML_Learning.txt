HTML 
--------------
HyperText Markup Language

The main purpose of HTML to design Web Pages. HTML has the following syntax:

<!doctype HTML>
<html>
   <head>
        <title>Title of Web Page</title>
   </head>
   <body>
         visible content on Web Page
    </body>
</html>

Case 17: How to Apply events in a Web Page Elements
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script>
        function display(){
            document.write("Display Even Numbers:"+"<br/>")
            for(let i=10;i<=40;i++){
                if(i%2==0){
                    document.write("Even Number :"+i+"<br/>")
                }
            }
        }
    </script>
</head>
<body>
    <h3>Execute Result:</h3>
    <button name="execute" onmouseout="display()">Execute</button>
</body>
</html>

Case 18: Design Alerts in Web Page
There are 3 Types of Alerts
1. Simple Alert
2. Confirm
3. prompt

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script>
        function showsimplealert(){
            alert("Welcome to HTML Learning !!!")
        }
        function showconfirm(){
            confirm("Are you Delete demoUser1 from Database?")
        }

        function showPrompt(){
            prompt("Enter the TestScript Name for Debug:")
        }
    </script>
</head>
<body>
    <h3 align="center">Show Alerts</h3>
    <button name="simplealert" onclick="showsimplealert()">Simple Alert</button> <br><br><br>
    <button name="confirmalert" onclick="showconfirm()">Confirm Alert</button> <br><br><br>
    <button name="promptalert" onclick="showPrompt()">Prompt Alert</button> <br><br><br>
</body>
</html>
